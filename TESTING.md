# Проверка первой версии управления Traveler

Дата: 6 ноября 2026. Среда: VPS KVM, Ubuntu 24.04.1 LTS,
ядро 6.8.0-48-generic, 2 ГБ RAM. Существующая установка wg-easy 15.5.0
с одним реальным клиентом. Секреты и адрес сервера в отчёт не включены.

## Проверено на VPS

- Bash syntax и компиляция Python: успешно.
- Три регрессионных unittest: успешно (приоритет .env, отказ при повреждённой
  копии до остановки сервисов, запрет восстановления из постороннего каталога).
- `doctor`: успешно; остановка Caddy обнаруживается с кодом 1.
- Повторный install с конфликтующими WG_PORT/WG_ADMIN_PASSWORD: сохранены
  .env, пользователи, клиенты и SQL-хуки.
- Одновременный запуск команды блокируется.
- Ручной backup/rollback: восстановлено полное содержимое тома; тестовый файл,
  созданный после бэкапа, исчез. Пароли/ключи/настройки сохранились.
- Обновление на ghcr.io/wg-easy/wg-easy:15.5.0: успешно, doctor проходит.
- Намеренно несовместимый caddy:2-alpine вместо wg-easy: запуск отклонён,
  автоматически восстановлены прежние образы и состояние всех томов.
- Несуществующий тег образа: обновление отказало, рабочие контейнеры сохранены.
- Смоделированы маркеры прерванного бэкапа и обновления: обычные команды
  блокируются, `rollback` без ID восстанавливает работу.
- После добавления fsync отдельно повторены backup/rollback и doctor.

Полный live-прогон завершился строкой `ALL LIVE TESTS PASSED`.
Сохранность данных сравнивалась по хешам без публикации содержимого.
После автоматического отката наблюдался новый handshake реального клиента.

## Ограничения проверки

Сценарии прерывания проверены сохранёнными маркерами, без физического
выключения VPS. Новая первичная установка этой версии на втором чистом VPS
и Ubuntu 22.04 отдельно не проверялась. Исходный установщик ранее успешно
установил этот сервер; новая версия проверена на миграции существующей установки.
Внешняя HTTPS-страница проверена отдельно. Полный VPN-трафик, IPv6-доступ
в интернет и прохождение DPI в разных сетях этим прогоном не подтверждены.

GitHub Actions дополнительно запускает синтаксические проверки и unittest
на Python 3.10/3.12. Состояние CI смотрите в Actions; локальная проверка
не означает, что удалённый CI уже завершился.
