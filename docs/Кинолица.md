# Кинолица

Статический сайт с попарным голосованием за портреты восьми актрис. Выбор меняет личный рейтинг Elo. Пропуск открывает другую пару, отмена возвращает предыдущий выбор, сброс очищает историю. Голоса хранятся в браузере по адресу сайта.

## Локальный запуск

Выполните команду из корня репозитория.

```bash
python -m http.server 8766 --bind 127.0.0.1 --directory split/site
```

Откройте [страницу на локальном сервере](http://127.0.0.1:8766/). Для работы сайта достаточно [статических файлов](../split/site/). Сборка, зависимости и база данных не нужны.

## Раздача через Caddy

Установщик Traveler включает сайт через `--site`. Для отдельного размещения поместите содержимое `split/site/` в каталог, доступный на чтение процессу Caddy, например `/srv/kinolitsa`. Укажите свой домен и путь в конфигурации сайта.

```caddyfile
club.example.com {
    root * /srv/kinolitsa
    encode zstd gzip
    file_server
}
```

На телефоне и компьютере работают одни и те же файлы. Портреты включены в комплект. У каждой фотографии в разделе «Фотографии и лицензии» указаны автор, страница на Wikimedia Commons и лицензия CC BY-SA 3.0 или 4.0. Карточки визуально кадрируют портреты, локальные файлы взяты из Wikimedia Commons без дополнительных изменений.
