# Статистика устройств Traveler

Сборщик считывает количество байтов на отправку и получение для каждого профиля sing-box. «Последняя активность» показывает время, когда сборщик заметил прирост любого счётчика. По этому времени нельзя определить, установлено ли соединение сейчас.

Сборщик опрашивает API раз в 15 секунд. Накопленные значения сохраняются после перезапуска sing-box и сборщика. Байты между последним опросом и остановкой sing-box могут потеряться. Используйте эти значения для наблюдения за устройствами. Отчётность с точным учётом требует отдельного измерения.

## Сборка sing-box с поддержкой статистики

Для подсчёта используется [V2Ray API sing-box](https://sing-box.sagernet.org/configuration/experimental/v2ray-api/). В стандартную сборку v1.14.4 модуль `with_v2ray_api` не включён. Скрипт Traveler собирает исходники из [закреплённого коммита sing-box](https://github.com/SagerNet/sing-box/commit/c005f35300ce76427dc285481ec5695f5b179cd2) с флагами официальной сборки для Linux и добавляет этот модуль. Архив Go 1.26.10 проверяется по [официальной контрольной сумме](https://go.dev/dl/?mode=json&include=all).

На Linux amd64 с `curl`, `git`, `tar` и GNU coreutils запустите:

```sh
bash split/build-traffic-sing-box.sh /tmp/traveler-sing-box-traffic.candidate
```

Путь должен указывать на новый файл. Сборка может занять несколько минут. Скрипт печатает версию, флаги и контрольную сумму, затем удаляет временную копию Go и исходников. Работающий бинарник sing-box и его настройки не меняются. Перед заменой бинарника проверьте конфигурацию командой `traveler-sing-box-traffic.candidate check -c /etc/traveler-origin/config.json` с абсолютным путём к собранному файлу.

## Развёртывание сборщика на origin

- В конфигурации sing-box задайте `experimental.v2ray_api.listen` равным `127.0.0.1:19090`, `stats.enabled` равным `true` и перечислите имена Trojan-профилей в `stats.users`. При добавлении или отзыве профиля список обновляет панель. API должен оставаться доступным только на loopback.
- Сборщик использует системные пакеты `python3-grpcio` и `python3-protobuf`. Путь к скрипту в юните по умолчанию — `/opt/traveler-panel/panel_traffic.py`.
- Юнит `traveler-panel-traffic.service` запускается отдельно от sing-box от системной учётной записи `traveler-panel-traffic` без доступа к оболочке. Её создаёт установщик. При ручной установке создайте эту учётную запись и одноимённую группу перед командами `systemctl daemon-reload` и `systemctl enable --now traveler-panel-traffic`.
- Проверить подключение к API можно через `journalctl -u traveler-panel-traffic -n 30`. Панель читает `/var/lib/traveler-panel-traffic/stats.json`. Сборщик записывает только имена профилей, число байтов и время последней активности. Адреса, назначения трафика и пароли не попадают в файл статистики.
